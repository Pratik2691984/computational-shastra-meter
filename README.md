# Computational Śāstra — Vedic Meter Explorer

Client-side Pingala meru explorer for [aigaane.in](https://aigaane.in).

## Open it

1. Download `index.html` from this repo (or from the Grok artifacts file `vedic_meter_explorer.html`).
2. Open the file in any browser. No server required.
3. Optional: GitHub Pages — Settings → Pages → Deploy from `main` / root.

Live preview after Pages is on:
`https://pratik2691984.github.io/computational-shastra-meter/`
